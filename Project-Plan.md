# CV Generator

## Project Goals

### Primary Goal
Build an automated system that takes a job posting and the Professional Portfolio as inputs and generates a tailored, evidence-based CV in PDF format.

### Learning Goal
Use the development of the project to build software-engineering skills directly relevant to Scientific Software Engineer roles.

## Inputs

- Job posting
- Professional Portfolio

## Output

- Tailored CV in PDF format

## Current Phase

Project architecture and planning.
